# Идеи на потом (после симулятора)

Не план, а парковка идей — чтобы не потерялись. Обсуждалось 2026-06-11.

---

## 1. «AST» вычёркиваем из словаря

Не идея, а решение: язык плоский (нет выражений, блоков, вложенности),
поэтому «дерево» честно выродилось в `[]Statement` — ровно то, что уже
лежит в `Parser.zig`. Структура правильная, менять нечего, просто не
называем её AST. Оговорка: если возьмёмся за п.2 — там дерево станет
настоящим (выражения!), и слово вернётся по делу.

## 2. Мини-компилятор подмножества C → sioasm

**Полноценный C-бэкенд (LLVM-таргет) — мёртвая идея**, причины
фундаментальные, не технические:
- два регистра (`dat` — только MC6000), значения зажаты в −999..999;
- нет стека и адресуемой памяти: указатели, массивы, рекурсия, спиллинг —
  некуда;
- лимит игры 9/14 строк на чип — нетривиальная функция не влезает физически.

**А вот игрушечное подмножество — реалистично и интересно:**
1–2 int-переменные, арифметика, `if/else` через `teq` + `+`/`-`,
`while` через `jmp`. Это тот же конвейер, что уже написан (лексер → парсер
→ эмиттер), плюс две настоящие новые темы:
- **парсер выражений** (вот где появится реальное AST и приоритеты
  операторов — recursive descent / Pratt);
- **кодоген**: разложить выражение на `acc`/`dat`, поняв на своей шкуре,
  что такое register allocation, когда регистров два.

Хороший «следующий уровень» сложности после симулятора.

## 3. `sio2arm` — мостик к настоящему ассемблеру (STM32 / Thumb-2)

Идея: учить реальный asm на материале, который уже понимаешь. Лучший
таргет — **STM32 (Cortex-M, Thumb-2)**, потому что там есть прямой
концептуальный близнец нашей главной фишки: SIO-шные `+`/`-` — это
предикатное исполнение, и ровно оно есть в Thumb-2 (IT-блоки:
`cmp` + `ite`, инструкции выполняются/пропускаются по флагу — родня
`teq` + `+`/`-`).

Естественный маппинг:

| SIO | Thumb-2 (Cortex-M) |
|---|---|
| `acc` | `r0` |
| `teq`/`tgt`/`tlt` | `cmp` + флаги |
| `+ instr` / `- instr` | IT-блок (`ite` + условные инструкции) |
| `jmp label` | `b label` |
| `slp` | `wfi` |
| порты `pN` | memory-mapped GPIO |
| XBus (блокирующий) | UART/SPI |

Почему не другие: x86_64 — предикации нет, синтаксис барочный;
Xtensa (ESP8266) — нишевый, мало учебных материалов.

Практическая форма: шпаргалка-таблица sio↔Thumb (выше — её зародыш) +
транспилер `sio2arm` как **второй эмиттер рядом с `Emitter.zig`** из уже
готовой `Program`. Выхлоп можно гонять в QEMU. Из двух идей эта дешевле
и даёт больше.
