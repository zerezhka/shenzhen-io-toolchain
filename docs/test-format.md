# Test format (draft)

See `specs/001-sio-toolchain/contracts/test-definition.schema.json` for the current schema draft.

## Local-only metadata

You may reference local-only text assets (e.g., extracted game `messages.*` and `descriptions.*`) in tests, but they must **not** be committed. See `docs/local-original-assets.md`.

## Signal dump adapter

For convenience, tests may be authored from user-supplied “signal dumps” (local-only) using the line format described in `specs/001-sio-toolchain/contracts/signal-dump.format.md`.
