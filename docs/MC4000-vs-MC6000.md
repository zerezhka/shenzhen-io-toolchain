# MC4000 vs MC6000 Comparison

## Key Differences

### MC4000 (Reduced-Functionality)
- **Program Memory**: 9 lines
- **General-Purpose Registers**: 1 (`acc` only)
- **XBus Pins**: 2 (`x0`, `x1`)
- **Simple I/O Pins**: 2 (`p0`, `p1`)
- **Total I/O Pins**: 4
- **Purpose**: Lower BOM costs, reduced functionality alternative

**Pin Configuration:**
```
x0  - XBus
p0  - simple I/O
p1  - simple I/O
x1  - XBus
```

**Registers:**
- `acc` - General purpose accumulator

---

### MC6000 (High Performance)
- **Program Memory**: 14 lines
- **General-Purpose Registers**: 2 (`acc`, `dat`)
- **XBus Pins**: 4 (`x0`, `x1`, `x2`, `x3`)
- **Simple I/O Pins**: 2 (`p0`, `p1`)
- **Total I/O Pins**: 6
- **Purpose**: Maximum power, centerpiece of MCxxxx family

**Pin Configuration:**
```
x0  - XBus
x1  - XBus
p0  - simple I/O
p1  - simple I/O
x3  - XBus
x2  - XBus
```

**Registers:**
- `acc` - General purpose accumulator
- `dat` - General purpose data register (additional on-chip storage)

---

## Summary Table

| Feature | MC4000 | MC6000 |
|---------|--------|--------|
| Program Memory | 9 lines | 14 lines |
| Registers | 1 (`acc`) | 2 (`acc`, `dat`) |
| XBus Pins | 2 (`x0`, `x1`) | 4 (`x0`, `x1`, `x2`, `x3`) |
| Simple I/O Pins | 2 (`p0`, `p1`) | 2 (`p0`, `p1`) |
| Total Pins | 4 | 6 |
| Use Case | Lower cost, simpler applications | Complex, demanding applications |

## Implications for Simulator

When implementing the simulator (Phase 4), we need to:

1. **Support both MCU models** - Allow configuration of which MCU type to simulate
2. **Validate register usage** - Reject programs that use `dat` on MC4000
3. **Validate pin usage** - Reject programs that use `x2`/`x3` on MC4000
4. **Program size limits** - Enforce 9-line limit for MC4000, 14-line limit for MC6000
5. **Register initialization** - Both `acc` and `dat` (if available) initialize to 0

## Notes

- Both MCUs share the same instruction set
- Both use the same programming language (MCxxxx)
- Simple I/O pins behave the same on both (input/output mode switching)
- XBus pins behave the same on both (discrete data packets -999 to 999)
